# AGENTS.md — AradLens_frontend

Single-file static AR tourism app for Arad. All app code lives in `index.html` (~5300 lines, ~229 KB, inline CSS + JS). No package.json, no build, no tests.

## Structure
- `index.html` — entire app: UI, CSS (`<style>` lines 11–1810; the iOS 26 "liquid glass" layer is the block commented `STRATUL „LIQUID GLASS”` from ~line 1252), body markup ~1812–2320, logic (single `<script>` from line 2322). Entry data: `const REPERE`, story chapters `const CHAPTERS`, `storyState`. **Public API layer** + preload near the end of the script.
- AradLens API (**public, read-only**): browser never calls `https://api.aradlens.binarysquad.club` directly (it publishes no CORS headers) — all calls go through the same-origin reverse proxy `/api/` (nginx `deploy/nginx/default.conf` in prod, `dev_server.py` locally). JS layer: `apiRequest(path, {timeoutMs})` — **GET only** (shared fetch, timeout via AbortController, 404/422/network/timeout mapped to friendly Romanian messages, no internals leaked, `console.warn` on unexpected statuses), `esc()` escapes API strings before innerHTML. Only these endpoints exist in this repo: `ApiHealth.check` (`GET /health`, gate), `CategoriesApi.list/get`, `LocationsApi.list/get` + `imageUrl` (`<img src="/api/locations/images/{id}">`), `ToursApi.list/get`. **There is deliberately no auth, token, login, POST/PUT/PATCH/DELETE or admin UI here — content management lives in the separate admin site.**
- API health gate: `#apiGate` full-screen overlay (z 80) covers everything from script load; `runApiGate()` checks `GET /api/health` (8 s timeout) → success runs `preloadAppData()` and then hides the gate; failure shows "Serverul AradLens nu este momentan disponibil…" + "Încearcă din nou" (manual retry only, no auto-loop, no blank screen).
- **Preload before the first tap:** `preloadAppData()` fetches locations, tours and categories in parallel, merges locations into `REPERE`, warms the images and pre-renders the category list, location list, compass band, album module bar and level map while the gate says "Se pregătesc obiectivele, traseele și albumul…". Opening a menu never triggers a fresh fetch.
- Public UI: **no locations/categories/tours rail rings any more.** The rail is theme capsule → gamemode → details → photo → album. `#locationsModal` opens as an **objective page on long-press (460 ms)** of a compass stop (`bindLongPress` → `openLocationPage`), rendering from cache instantly and refreshing via `GET /locations/{id}`; `#toursModal` remains in the DOM but is no longer reachable; `#categoriesModal` is a plain read-only list. All counts pluralized in Romanian ("un tur"/"N tururi", "o locație"/"N locații", "o categorie"/"N categorii").
- `primaria-1901.jpg` — only historic photo asset, referenced by `REPERE[2].foto`.
- `fonts/` — self-hosted OFL display face (AradLens Display) + license; must be committed or `@font-face` 404s in prod.
- `docker-compose.yml` + `deploy.sh` — prod serving; compose mounts `deploy/nginx/default.conf` into the nginx image.
- `dev_server.py` + `Start-AradLens.bat` — local launcher: static files + `/api` proxy on 127.0.0.1:8010 (falls back to plain `http.server` if `dev_server.py` is missing).
- `docs/codebase.md` — full codebase walkthrough (read this before large changes).
- `.opencode/commands/` — 54 slash commands (one per skill in `.agents/skills/`); skills themselves stay gitignored, commands are committed.

## Run locally
- Static only: `docker compose up --build` → http://localhost:8010, or `python3 -m http.server 8010`.
- Sensors (camera, GPS, compass) require **HTTPS + mobile + user gesture** (`#startBtn` handler requests motion permission first, then camera/geo). Desktop shows `#desktopPlaceholder`; `Continuă în mod previzualizare` bypasses for layout work.
- No lint/typecheck/test commands exist.

## Conventions / gotchas
- State is in-memory globals + 2 `localStorage` keys: `aradlens_user_photos` (captured dataURLs, per-landmark), `aradlens_story_state` (mode story/free, per-chapter `currentStep`/`completed`, rewards). No backend; "save permanently" TODO is in `executePhotoCapture()` / capture modal text.
- Photo capture is canvas snapshot from `<video id="cam">`, not native camera API. Proximity gate is 200 m (`checkLandmarkProximity`), `notifiedLandmarksInSession` Set prevents repeat toasts.
- Album page (`#albumModal`) is a **vertical linear level map in modules** (`getAlbumModule`/`albumStops`/`renderLevelMap`): first stop at the bottom, scroll upward like game level-select; order/length come from the chosen module (`Liber` = chronological 1865→1913, `Cap. I–III` = the chapter's `landmarkIndices`, `tur:<id>` = a tour from the API with `Oprirea n` labels), NOT GPS positions — keep the "schematic, not GPS" disclaimer in UI. Tours are merged here (the old routes modal is unreachable). The header and the module chip bar are sticky; only `#albumMapTab` scrolls, and `scroll-padding-top` keeps a centred stop clear of the chips. Tapping a stop opens the `Atunci/Acum` compare popup (`#albumCompareModal`).
- Stop selector is the curved **compass band** (`<nav id="snapRail">`, last child of `.bottom`; JS `renderCompassBand`): an amber reticle marks the selected stop, drag / mouse wheel / arrow keys scroll the tape, `BAND_SLOT` (108 px spacing) + `BAND_SAG`/`perspective rotateX(13deg)` shape the arc. It is story-aware — chapter steps render as `.locked` (padlock, not selectable), `.completed` (teal) or current (amber). **It carries every objective from the API in free mode**, and a 460 ms long-press on a stop opens that objective's location page.
- **Theme is one material: iOS 26 liquid glass.** Tokens `--glass-*` (+ `--glass-solid`/`--glass-veil`/`--bar-solid` for fallbacks), springs `--spring`/`-snappy`/`-bouncy`/`-soft` with Apple durations (`--dur-press` 100 ms, `--dur-spring` 475 ms). Rules: exactly one `backdrop-filter` per stacking path (veils are scrims; the sticky album chip bar uses a solid fill, not a second blur); `backdrop-filter` must be written literally, never as `backdrop-filter: var(--x)` — Safari 18.2+ drops the whole declaration. `@media (prefers-reduced-transparency: reduce)` is what Windows reports when transparency effects are off, so the fallback keeps the sheen/edge instead of going flat. The brand mark is `.brand-lens` (archival photo under a specular disc + chromatic rim), not a plain wordmark, and the favicon is the same lens in inline SVG.
- **Never print a coordinate.** The API has no street field: `streetFor()` resolves `STRAZI_REPERE` → `STRAZI_API_ID` → a `STREET_RE` match in the description → `"Arad"`, and every surface (info card meta, `#coords`, location cards/detail, tour stops, album compare + level-map subtitles) shows the street.
- Story mode (`CHAPTERS` ~line 1558, `storyState` ~line 1616, `#gamemodeModal`): captures must follow chapter order (`showCaptureFeedback` warns otherwise), each shot opens `#storyLoreModal`, the last step opens `#rewardModal` (its album shortcut reopens the level map); free mode ignores order.
- `index.html` is UTF-8 (CRLF, no BOM) with intact Romanian diacritics. Tools that decode it with a legacy codepage (e.g. PowerShell `Get-Content` without `-Encoding UTF8`) show mojibake (`ș`→`ET`, `ț`→`E>`) — a display artifact, not corruption. Never "fix" strings based on a garbled view.
- Do not split `index.html` into bundles or add a framework without explicit approval — deploy expects a flat static root served by nginx.

## Deploy
- Push to `main` triggers `.github/workflows/deploy.yml` → SSH to server, runs `sudo -n $DEPLOY_PATH/deploy.sh` (`git pull && docker compose down/build/up -d`). Needs secrets: `SSH_HOST/USER/PRIVATE_KEY`, `DEPLOY_PATH`, optional `SSH_PORT`.
- Never commit AI local dirs (see `.gitignore`): `.agents/`, `.codex/`, `.impeccable/`, `skills-lock.json`, `.github/agents|hooks|skills/`.
